## Setup - Phase 11 Real Working

### Prerequisites
- JDK 17, Android Studio Hedgehog+, Android SDK 34

### Steps
1. Clone - branch `arena/01a0ba55-android-app`
2. `local.properties`: `sdk.dir=/path/to/sdk` + optional `keystore.path`, `keystore.password`, `key.alias`, `key.password` for Play Store signing
3. `gradle wrapper --gradle-version 8.7 && chmod +x gradlew`
4. `./gradlew assembleDebug` - fetches Sora 0.23.6, JGit 6.10.0, LSP4J 0.22.0, kotlinx.serialization, Rhino 1.7.14, JSch 0.1.55, Retrofit, OkHttp from Maven Central

Run on device - SAF picker works on Android 11+, TextMate 100 langs highlighting (including matlab, vb, xaml, rst, log, bicep, hcl, thrift, jsonc, shaderlab), file watcher auto-refresh, file explorer with icon themes 100 langs, breadcrumbs advanced, minimap advanced, bracket pair colorization, terminal persistent shell with ANSI 256+true-color + PTY full, Marketplace UI, Tasks UI, Diff 3-way/Merge, WorkbenchLayout with activityBar/sidebar/editor/panel/statusbar, LayoutService toggle sidebar/panel, EditorGroups split up to 3 groups, LspClient/DapClient Content-Length framing
